# Time

The passing of time. Weaver uses it only to look at omp again, to read the usage limits again, to export the system's certificate authorities again and to drop what the File view keeps after it stops being shown; it never uses it to decide that an agent stopped working.

## Events

### RECHECK_DUE
A few seconds have passed while Weaver waits for omp's installer or a provider login running in the system terminal.

### UPDATE_CHECK_DUE
An hour has passed since Weaver last asked omp whether a newer version exists.

### USAGE_REFRESH_DUE
Five minutes have passed since the last reading of the usage limits started, or none has started since Weaver started, while omp is ready and at least one window of Weaver is on the screen.

### CERTIFICATES_REFRESH_DUE
A day has passed since the last export of System Certificates ended, while Weaver stays open and the setting is on.

### FILE_VIEW_RELEASE_DUE
A short while has passed since the File view of a window stopped being shown.
