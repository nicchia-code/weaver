# Requests

## design-request
- **Name:** every text of the interface calls it a request (`Request`, `New Request`, `Untitled request`, `Setup request`, `Design request`), never a work item; so do the texts Weaver gives agents when they point the developer to the Board's control (`New Request` in the Backlog).
- **Draft card:** each request being written is a card of the Backlog (`requirements/ui#work`), after the open Proposals and Drifts and before the ghosts, oldest first. It has the look of the other cards (`requirements/ui#proposal`): Surface, Line ring and the soft shadow of a card on a lane, radius 12 px, controls in a footer after a `#EFEDE7` rule. Top to bottom:
  1. the tag `Request` where the other cards show their id;
  2. the title, 15 px semibold, at most 3 lines then `…`: the first heading, else the first line, else `Untitled request`;
  3. `Not sent · <created>` in Muted, the creation time as the Jobs list writes times: `HH:MM` today, else `D MMM HH:MM`;
  4. the footer: `Send` (primary, `SendHorizontal`), disabled while the text is empty after trimming, tooltip `Write the request first.`; then `Discard` (`Trash2`), with the AlertDialog `Discard this request?` / `Its file and images are deleted.`, `Discard` (destructive) and `Cancel` (focus).
- Clicking the draft card outside its controls, or Enter on its title, opens the request in the request editor; it has no details dialog. A failed send or discard from the card shows the error toast the editor shows (`The request could not be sent.`, `The request could not be discarded.`, or the reason given).
- **Request editor:** one request across the whole Board view, in place of the Board. Its header: the back control on the left, the heading `Setup request` or `Design request`, the save status and the request's controls. No list of requests, no `New request`, no `Draft` or `Sent` badge; and the Board shows no strip counting the open requests.
- It opens with one request: a new one from the Backlog's `New Request` or the empty Backlog's `Request`; the oldest request being written, else a new one, from Start from Scratch (`requirements/ui#project`); a draft from its card or its row in the palette (`requirements/ui#window`); a sent request from `View request` of its job (`requirements/ui#job`). A request being written opens focused in the text.
- **Back control:** `← Board`, which shows the Board; `← Jobs` when the request was opened from `View request`, which shows that job's conversation again.
- **Leaving an empty request:** leaving the editor (the back control, another view) while the text is empty after trimming deletes the request and its images, with no confirmation and no toast; so does closing the window while the editor shows it. A request made only of images is not empty.
- **Editing:** a monospace textarea with soft wrap filling the pane. A `Preview` toggle shows the rendered Markdown (shared renderer) side by side from ~900 px of pane width, in place of the text below it; the preview updates within 150 ms of typing.
- **Autosave:** the file is written 500 ms after the last keystroke and on blur, view switch and window close. Status text in the header: `Saving…`, `Saved`, or `Could not save: <reason>.` (error colour; the text stays and the next change retries). Typing starts no process.
- An outside change to the file reloads the editor when nothing is pending; otherwise Weaver's version is written and a warning toast says `The request changed on disk; Weaver kept your version.` A request deleted outside Weaver closes the editor, back to where it was opened from, with the warning toast `The request was deleted outside Weaver.`
- **Send:** primary `Send` (`SendHorizontal`), also `Ctrl/Cmd+Enter`; disabled while the text is empty after trimming, tooltip `Write the request first.` Once sent, the editor closes and the Board shows, with the job's ghost where the draft card was; a failed send leaves the editor open with its error toast.
- **Discard:** `Discard` (`Trash2`), AlertDialog `Discard this request?` / `Its file and images are deleted.`, `Discard` (destructive) and `Cancel` (focus). Once discarded, the editor closes and the Board shows.
- **Sent:** read-only rendered view with a banner `Sent to the agent · <job name>` and `Open conversation`, which shows that job's conversation. When the request is consumed or discarded while shown, the view closes back to the job's conversation, without a toast; when its job ends without a Proposal while shown, the same view becomes the writable request with the banner of **Returned**.
- **Returned:** a request back in writing after its job ended without a Proposal is an ordinary draft card again; opened, it shows the banner `The job ended without a Proposal. Change the request and send it again.`
- **Images:** PNG, JPEG, GIF or WebP pasted or dropped into the text are saved in the request's images folder next to it as `image-<n>.<ext>` (next free number), and `![](<images folder>/image-<n>.<ext>)` is inserted at the cursor. At most 10 MB per image; anything else is refused with an error toast `Only PNG, JPEG, GIF or WebP images up to 10 MB.` The preview shows images only from that folder.
